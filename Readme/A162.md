## 문제 풀이

### 문제 링크
[159994. 카드 뭉치 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/159994)

---

### 문제 설명
> 코니는 영어 단어가 적힌 카드 뭉치 두 개를 선물로 받았습니다. 코니는 다음과 같은 규칙으로 카드에 적힌 단어들을 사용해 원하는 순서의 단어 배열을 만들 수 있는지 알고 싶습니다.
> 1. 원하는 카드 뭉치에서 카드를 순서대로 한 장씩 사용합니다.
> 2. 한 번 사용한 카드는 다시 사용할 수 없습니다.
> 3. 카드를 사용하지 않고 다음 카드로 넘어갈 수 없습니다.
> 4. 기존에 주어진 카드 뭉치의 단어 순서는 바꿀 수 없습니다.
> 문자열 배열 `cards1`, `cards2`와 원하는 단어 배열 `goal`이 매개변수로 주어질 때, `goal`을 만들 수 있다면 "Yes"를, 만들 수 없다면 "No"를 return 하도록 solution 함수를 완성해주세요.

---

### 접근 방식
1.  **투 포인터**:
    -   `cards1`과 `cards2`의 현재 사용 위치를 가리키는 인덱스 `i`, `j`를 0으로 초기화한다.
2.  **순차 검증**:
    -   `goal`에 있는 단어를 순서대로 확인한다.
    -   현재 단어가 `cards1[i]`와 같다면 `i`를 증가시킨다.
    -   그렇지 않고 `cards2[j]`와 같다면 `j`를 증가시킨다.
    -   둘 다 아니라면 해당 순서로 단어를 만들 수 없으므로 "No"를 반환한다.
3.  **반환**:
    -   `goal`의 모든 단어를 성공적으로 처리했다면 "Yes"를 반환한다.

---

### 풀이 코드

```cpp
#include <string>
#include <vector>

using namespace std;

string solution(vector<string> cards1, vector<string> cards2, vector<string> goal) {
    int i = 0, j = 0;

    for (const string& w : goal) {
        if (i < (int)cards1.size() && cards1[i] == w) {
            i++;
        } else if (j < (int)cards2.size() && cards2[j] == w) {
            j++;
        } else {
            return "No";
        }
    }
    return "Yes";
}
```
