## 문제 풀이

### 문제 링크
[138477. 명예의 전당 (1) – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/138477)

---

### 문제 설명
> "명예의 전당"이라는 TV 프로그램에서는 매일 1명의 가수가 노래를 부르고, 시청자들의 문자 투표수로 점수를 받습니다.
> 지금까지 출연한 가수들의 점수 중 상위 `k`번째 이내이면 해당 가수의 점수를 명예의 전당 목록에 올립니다.
> 프로그램 시작 이후 매일, "명예의 전당"의 최하위 점수의 변동 흐름을 알고 싶습니다.
> 매일 출연한 가수의 점수 `score`와 명예의 전당 목록의 점수 개수 `k`가 주어질 때, 매일 발표된 명예의 전당의 최하위 점수를 배열에 담아 return 하도록 solution 함수를 완성해주세요.

---

### 접근 방식
1.  **우선순위 큐 (Min Heap)**:
    -   명예의 전당에 있는 상위 `k`개의 점수를 관리하고, 그중 최솟값을 빠르게 확인하기 위해 최소 힙(`priority_queue` with `greater<int>`)을 사용한다.
2.  **점수 처리**:
    -   매일 가수의 점수를 힙에 넣는다 (`push`).
    -   만약 힙의 크기가 `k`보다 커지면, 가장 작은 점수를 제거한다 (`pop`). 이렇게 하면 항상 상위 `k`개의 점수(또는 `k`일 미만일 경우 전체 점수)만 힙에 남게 된다.
3.  **최하위 점수 기록**:
    -   모든 처리가 끝난 후 힙의 최상단(`top`)에 있는 값이 명예의 전당 최하위 점수이므로, 이를 결과 배열에 추가한다.

---

### 풀이 코드

```cpp
#include <vector>
#include <queue>
#include <functional>

using namespace std;

vector<int> solution(int k, vector<int> score) {
    priority_queue<int, vector<int>, greater<int>> pq; 
    vector<int> ans;
    ans.reserve(score.size());

    for (int s : score) {
        pq.push(s);
        if ((int)pq.size() > k) pq.pop();     
        ans.push_back(pq.top());              
    }

    return ans;
}
```
