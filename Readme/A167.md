## 문제 풀이

### 문제 링크
[134240. 푸드 파이트 대회 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/134240)

---

### 문제 설명
> 수웅이는 푸드 파이트 대회를 개최하려고 합니다. 이 대회에서 선수들은 1대 1로 대결하며, 매 대결마다 음식의 종류와 양이 바뀝니다. 대결은 준비된 음식을 일렬로 배치한 뒤, 한 선수는 왼쪽부터 오른쪽으로, 다른 선수는 오른쪽부터 왼쪽으로 순서대로 먹는 방식으로 진행됩니다. 중앙에 있는 물을 먼저 마시는 선수가 승리합니다.
> 두 선수가 먹는 음식의 종류와 양이 같아야 하며, 칼로리가 낮은 음식부터 먹어야 합니다.
> 주어진 음식(`food`)으로 대회를 위한 음식 배치를 나타내는 문자열을 구하시오. `food[i]`는 i번 음식의 개수이며, `food[0]`은 물(1개)입니다.
> 1번 음식부터 번호가 1, 2, 3... 인 형태로 배치되며, 좌우 대칭이어야 합니다.

---

### 접근 방식
1.  **왼쪽 부분 문자열 생성**:
    -   1번 음식부터 마지막 음식까지 순회한다 (`food` 배열의 인덱스 1부터).
    -   각 음식의 개수 `food[i]`를 2로 나눈 몫만큼 반복하여 해당 음식 번호(i)를 문자열 `left`에 추가한다. (홀수 개라면 1개는 버려진다.)
2.  **오른쪽 부분 문자열 생성**:
    -   `left` 문자열을 복사한 뒤 뒤집어서 `right` 문자열을 만든다.
3.  **최종 문자열 조합**:
    -   `left` + "0" (물) + `right` 순서로 이어 붙여 결과를 반환한다.

---

### 풀이 코드

```cpp
#include <string>
#include <algorithm>
#include <vector>

using namespace std;

string solution(vector<int> food) {
    string left;

    for (int i = 1; i < (int)food.size(); i++) {
        int k = food[i] / 2;          // 양쪽에 놓을 수 있는 개수
        left.append(k, char('0' + i)); // i는 1~9라고 가정(문제 조건상 OK)
    }

    string right = left;
    reverse(right.begin(), right.end());

    return left + "0" + right;
}
```
