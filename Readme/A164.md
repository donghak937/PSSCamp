## 문제 풀이

### 문제 링크
[142086. 가장 가까운 같은 글자 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/142086)

---

### 문제 설명
> 문자열 `s`가 주어졌을 때, `s`의 각 위치마다 자신보다 앞에 나왔으면서, 자신과 가장 가까운 곳에 있는 같은 글자가 어디에 있는지 알고 싶습니다.
> 예를 들어, `s = "banana"`라고 할 때, 
> - 'b': 처음 나왔으므로 -1
> - 'a': 처음 나왔으므로 -1
> - 'n': 처음 나왔으므로 -1
> - 'a': 앞(인덱스 1)에 'a'가 존재하므로 3 - 1 = 2
> - 'n': 앞(인덱스 2)에 'n'이 존재하므로 4 - 2 = 2
> - 'a': 앞(인덱스 1, 3)에 'a'가 존재하지만 가장 가까운 것은 인덱스 3이므로 5 - 3 = 2
> 각 문자마다 자신보다 앞에 나온 같은 글자 중 가장 가까운 것과의 거리를 담은 배열을 반환하시오. 없다면 -1을 담습니다.

---

### 접근 방식
1.  **위치 기록**:
    -   알파벳 소문자 'a'~'z'의 마지막 등장 인덱스를 저장할 배열 `last`(크기 26)를 생성하고 -1로 초기화한다.
2.  **거리 계산**:
    -   문자열 `s`를 처음부터 순회한다.
    -   현재 문자 `s[i]`의 마지막 등장 위치가 -1이라면, 처음 등장한 것이므로 결과에 -1을 추가한다.
    -   아니라면, 현재 인덱스 `i`에서 마지막 등장 인덱스 `last[idx]`를 뺀 값을 결과에 추가한다.
3.  **갱신**:
    -   현재 문자 `s[i]`의 마지막 등장 위치를 현재 인덱스 `i`로 갱신한다.

---

### 풀이 코드

```cpp
#include <string>
#include <vector>

using namespace std;

vector<int> solution(string s) {
    vector<int> last(26, -1); 
    vector<int> ans;
    ans.reserve(s.size());

    for (int i = 0; i < (int)s.size(); i++) {
        int idx = s[i] - 'a';
        if (last[idx] == -1) ans.push_back(-1);
        else ans.push_back(i - last[idx]);

        last[idx] = i;
    }
    return ans;
}
```
