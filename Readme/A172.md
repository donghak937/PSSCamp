## 문제 풀이

### 문제 링크
[131705. 삼총사 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/131705)

---

### 문제 설명
> 한국중학교 학생들의 번호를 나타내는 정수 배열 `number`가 매개변수로 주어집니다. 학생들 중 서로 다른 3명을 골라 번호를 더했을 때 0이 되면 이 3명의 학생을 '삼총사'라고 합니다.
> 삼총사를 만들 수 있는 방법의 수를 구하시오.

---

### 접근 방식
1.  **브루트 포스 (완전 탐색)**:
    -   주어진 `number` 배열의 크기가 작음(최대 13)으로, 3중 반복문을 사용하여 가능한 모든 조합을 확인한다.
    -   첫 번째 학생 `i` (0 ~ n-1)
    -   두 번째 학생 `j` (i+1 ~ n-1)
    -   세 번째 학생 `k` (j+1 ~ n-1)
2.  **조건 확인**:
    -   `number[i] + number[j] + number[k] == 0` 인 경우 카운트를 증가시킨다.

---

### 풀이 코드

```cpp
#include <vector>

using namespace std;

int solution(vector<int> number) {
    int n = (int)number.size();
    int cnt = 0;

    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            for (int k = j + 1; k < n; k++) {
                if (number[i] + number[j] + number[k] == 0) cnt++;
            }
        }
    }
    return cnt;
}
```
