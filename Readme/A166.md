## 문제 풀이

### 문제 링크
[147355. 크기가 작은 부분문자열 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/147355)

---

### 문제 설명
> 숫자로 이루어진 문자열 `t`와 `p`가 주어질 때, `t`에서 `p`와 길이가 같은 부분문자열 중에서, 이 부분문자열이 나타내는 수가 `p`가 나타내는 수보다 작거나 같은 것이 나오는 횟수를 return하는 solution 함수를 완성하세요.
> 예를 들어, `t`="3141592", `p`="271" 인 경우, `t`의 부분문자열은 314, 141, 415, 159, 592입니다. 이 중 271보다 작거나 같은 수는 141, 159 2개입니다.
> (`p`의 길이는 1 이상 18 이하입니다.)

---

### 접근 방식
1.  **슬라이딩 윈도우**:
    -   문자열 `t`에서 길이가 `p.size()`인 부분문자열을 순차적으로 추출한다.
    -   인덱스 `i`는 0부터 `t.size() - p.size()`까지 순회한다.
2.  **크기 비교**:
    -   추출한 부분문자열(`b`)을 숫자로 변환하여 `p`를 숫자로 변환한 값과 비교한다.
    -   **주의**: `p`의 길이는 최대 18자리이므로, 32비트 정수형(`int`, `long`) 범위를 넘을 수 있다. 따라서 64비트 정수형(`long long`)으로 변환하는 `stoull` 함수를 사용해야 한다.
3.  **카운트**:
    -   `stoull(b) <= stoull(p)` 조건을 만족하면 카운트를 증가시킨다.

---

### 풀이 코드

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(string t, string p) {
    int answer = 0;
    string b = "";
    for (int i = 0; i < t.size(); i++) {
        if (i + p.size()-1 == t.size()) break;
        else {
            for (int j = i; j < p.size() + i; j++) {
                b += t[j];
            }
            if (stoull(b) <= stoull(p)) answer++;
            b = "";
        }
    }
    return answer;
}
```
