## 문제 풀이

### 문제 링크
[160586. 대충 만든 자판 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/160586)

---

### 문제 설명
> 휴대폰의 자판은 컴퓨터 키보드 자판과는 다르게 하나의 키에 여러 개의 문자가 할당될 수 있습니다. 키 하나에 여러 문자가 할당된 경우, 동일한 키를 연속해서 빠르게 누르면 할당된 순서대로 문자가 바뀝니다.
> 1번 키에 "A", "B", "C" 순서대로 문자가 할당되어 있다면 1번 키를 한 번 누르면 "A", 두 번 누르면 "B", 세 번 누르면 "C"가 되는 식입니다.
> 1부터 N번까지 각 자판 키에 어떤 문자들이 할당되어 있는지(`keymap`) 그리고 작성하려는 문자열들(`targets`)이 주어질 때, 각 문자열을 작성하기 위해 키를 최소 몇 번 눌러야 하는지 구하시오.

---

### 접근 방식
1.  **최소 횟수 매핑**:
    -   각 문자('A'~'Z')를 입력하기 위해 눌러야 하는 최소 횟수를 저장하는 배열(`press`)을 만든다.
    -   `keymap`을 순회하면서 각 문자가 등장하는 가장 앞쪽 인덱스(누르는 횟수)를 기록한다.
2.  **타겟 문자열 계산**:
    -   `targets`의 각 문자열을 순회하며, 구성 문자들의 최소 누름 횟수를 합산한다.
    -   만약 `press` 배열에 기록되지 않은 문자(입력 불가능)가 포함되어 있다면 해당 타겟은 작성할 수 없으므로 `-1`을 저장한다.
3.  **반환**:
    -   각 타겟에 대한 결과를 담아 반환한다.

---

### 풀이 코드

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

vector<int> solution(vector<string> keymap, vector<string> targets) {
    vector<int> press(26, 1000000000);

    for (string km : keymap) {
        for (int i = 0; i < (int)km.size(); i++) {
            int idx = km[i] - 'A';
            press[idx] = min(press[idx], i + 1);
        }
    }

    vector<int> ans;
    for (string t : targets) {
        int sum = 0;
        bool ok = true;

        for (char c : t) {
            int idx = c - 'A';
            if (press[idx] == 1000000000) {
                ok = false;
                break;
            }
            sum += press[idx];
        }

        ans.push_back(ok ? sum : -1);
    }

    return ans;
}
```
