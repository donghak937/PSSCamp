## 문제 풀이

### 문제 링크
[136798. 기사단원의 무기 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/136798)

---

### 문제 설명
> 기사단원의 수를 나타내는 정수 `number`와 이웃나라와 협약으로 정해진 공격력의 제한수치를 나타내는 정수 `limit`, 제한수치를 초과한 기사가 사용할 무기의 공격력을 나타내는 정수 `power`가 주어집니다.
> 각 기사는 자신의 기사 번호의 약수 개수에 해당하는 공격력을 가진 무기를 구매하려 합니다.
> 단, 공격력이 `limit`보다 크다면, 협약에 의해 `power`에 해당하는 공격력을 가진 무기를 구매해야 합니다.
> 무기점의 주인은 무기를 만들기 위해 무기의 공격력 1당 1kg의 철이 필요합니다. 무기를 모두 만들기 위해 필요한 철의 무게를 구하시오.

---

### 접근 방식
1.  **약수 개수 구하기**:
    -   1부터 `number`까지 각 숫자의 약수 개수를 구해야 한다.
    -   이중 루프(배수법)를 사용하여 1부터 `number`까지 효율적으로 약수 개수를 카운트한다. (`i`의 배수 `j`에 대해 `divCnt[j]++`)
    -   혹은 제곱근까지만 순회하여 구하는 방법도 있지만, 여기서는 배수법을 사용하여 $O(N \log N)$에 전체 약수 개수를 전처리한다.
2.  **공격력 제한 적용**:
    -   각 기사 번호(`i`)에 대해 약수 개수 `divCnt[i]`가 `limit`을 초과하는지 확인한다.
    -   초과하면 `power`를 더하고, 아니면 `divCnt[i]`를 더한다.
3.  **총합 반환**:
    -   계산된 철의 무게 총합을 반환한다.

---

### 풀이 코드

```cpp
#include <vector>

using namespace std;

int solution(int number, int limit, int power) {
    vector<int> divCnt(number + 1, 0);

    for (int i = 1; i <= number; i++) {
        for (int j = i; j <= number; j += i) {
            divCnt[j]++;
        }
    }

    int sum = 0;
    for (int i = 1; i <= number; i++) {
        if (divCnt[i] > limit) sum += power;
        else sum += divCnt[i];
    }

    return sum;
}
```
