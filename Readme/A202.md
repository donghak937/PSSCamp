## 문제 풀이

### 문제 링크
[1935. 후위 표기식2 – 백준](https://www.acmicpc.net/problem/1935)

---

### 문제 설명
> 후위 표기식과 각 피연산자에 대응하는 값이 주어졌을 때, 그 식을 계산하는 프로그램을 작성하시오.
> 첫째 줄에 피연산자의 개수 `N`(1 ≤ N ≤ 26)이 주어집니다.
> 둘째 줄에는 후위 표기식이 주어집니다. (피연산자는 A~Z의 영대문자)
> 셋째 줄부터 N+2번째 줄까지는 각 피연산자에 대응하는 값이 순서대로 주어집니다. (A의 값, B의 값, ... 순)
> 계산 결과는 소수점 둘째 줄까지 출력한다.

---

### 접근 방식
1.  **값 매핑**:
    -   피연산자(A~Z)에 대응하는 값을 `vector`에 저장한다. `val[c - 'A']`로 접근 가능하도록 한다.
2.  **스택 활용**:
    -   후위 표기식을 앞에서부터 순회한다.
    -   **피연산자**를 만나면 스택에 해당 값을 `push`한다.
    -   **연산자**를 만나면 스택에서 두 개의 값(`b`, `a`)을 `pop`하여 연산(`a op b`)을 수행하고 결과를 다시 스택에 `push`한다. (먼저 꺼낸 값이 뒤 연산자, 나중에 꺼낸 값이 앞 연산자임에 주의)
3.  **결과 출력**:
    -   모든 연산이 끝나면 스택에 하나의 값이 남는다. 이를 소수점 둘째 자리까지 출력한다.

---

### 풀이 코드

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <string>
#include <iomanip>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;

    string expr;
    cin >> expr;

    vector<double> val(N);
    for (int i = 0; i < N; i++) cin >> val[i];

    stack<double> st;

    for (char c : expr) {
        if ('A' <= c && c <= 'Z') {
            st.push(val[c - 'A']);
        } else {
            double b = st.top(); st.pop();
            double a = st.top(); st.pop();

            if (c == '+') st.push(a + b);
            else if (c == '-') st.push(a - b);
            else if (c == '*') st.push(a * b);
            else if (c == '/') st.push(a / b);
        }
    }

    cout << fixed << setprecision(2) << st.top() << "\n";
    return 0;
}
```
