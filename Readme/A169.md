## 문제 풀이

### 문제 링크
[133502. 햄버거 만들기 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/133502)

---

### 문제 설명
> 햄버거 가게에서 일을 하는 상수는 햄버거를 포장해야 합니다. 햄버거 재료는 빵(1), 야채(2), 고기(3) 순으로 주어지며, 햄버거는 반드시 아래서부터 **빵 – 야채 – 고기 – 빵 (1-2-3-1)** 순서로 쌓여야 포장할 수 있습니다.
> 재료의 정보가 담긴 정수 배열 `ingredient`가 주어졌을 때, 상수가 포장하는 햄버거의 개수를 구하시오.
> (재료는 순서대로 들어오며, 포장된 재료는 사라지고 남은 재료들이 붙어서 다시 햄버거를 만들 수도 있습니다.)

---

### 접근 방식
1.  **스택 활용**:
    -   들어오는 재료를 순서대로 `vector` 기반의 스택(`st`)에 쌓는다.
2.  **패턴 확인**:
    -   스택에 4개 이상의 재료가 쌓였을 때, 마지막 4개의 재료가 `1, 2, 3, 1` (빵, 야채, 고기, 빵)인지 확인한다.
    -   `st[size-4] == 1`, `st[size-3] == 2`, `st[size-2] == 3`, `st[size-1] == 1`
3.  **햄버거 포장**:
    -   패턴이 일치하면 햄버거 하나를 포장한 것이므로 카운트(`cnt`)를 증가시키고, 사용된 4개의 재료를 스택에서 제거(`pop_back`)한다.
    -   남은 재료들은 스택에 그대로 유지되어, 이후 들어오는 재료 혹은 기존 재료와 합쳐져 다시 햄버거가 될 수 있는지 검사 대상이 된다.

---

### 풀이 코드

```cpp
#include <vector>

using namespace std;

int solution(vector<int> ingredient) {
    vector<int> st;
    st.reserve(ingredient.size());

    int cnt = 0;

    for (int x : ingredient) {
        st.push_back(x);

        if (st.size() >= 4) {
            int n = (int)st.size();
            if (st[n - 4] == 1 && st[n - 3] == 2 && st[n - 2] == 3 && st[n - 1] == 1) {
                st.pop_back();
                st.pop_back();
                st.pop_back();
                st.pop_back();
                cnt++;
            }
        }
    }

    return cnt;
}
```
