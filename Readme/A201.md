## 문제 풀이

### 문제 링크
[17413. 단어 뒤집기 2 – 백준](https://www.acmicpc.net/problem/17413)

---

### 문제 설명
> 문자열 `S`가 주어졌을 때, 이 문자열에서 단어만 뒤집으려고 합니다.
> 문자열 `S`는 아래와 같은 규칙을 따릅니다.
> 1. 알파벳 소문자('a'-'z'), 숫자('0'-'9'), 공백(' '), 특수 문자('<', '>')로만 이루어져 있습니다.
> 2. 문자열의 시작과 끝은 공백이 아닙니다.
> 3. '<'와 '>'가 문자열에 있는 경우 번갈아가며 등장하며, '<'이 먼저 등장합니다. 또, 두 문자의 개수는 같습니다.
> 태그는 '<'로 시작해서 '>'로 끝나는 길이가 3 이상인 부분 문자열이고, '<'와 '>' 사이에는 알파벳 소문자와 공백만 있습니다.
> 단어는 알파벳 소문자와 숫자로 이루어진 부분 문자열이고, 연속하는 두 단어는 공백 하나로 구분됩니다. 태그는 단어가 아니며, 태그와 단어 사이에는 공백이 없습니다.

---

### 접근 방식
1.  **태그와 단어 구분**:
    -   문자열을 처음부터 끝까지 순회하며 태그 내부인지(`inTag`) 단어인지 구분한다.
2.  **태그 처리**:
    -   '<'를 만나면 이전에 쌓아둔 단어(`word`)가 있다면 뒤집어서 출력하고 초기화한다. 그 후 태그 모드로 진입(`inTag = true`)하여 문자를 그대로 출력한다.
    -   '>'를 만나면 태그가 끝나므로 모드를 해제(`inTag = false`)한다.
3.  **단어 처리**:
    -   태그 밖에서 문자가 나오면 `word` 문자열에 쌓는다.
    -   공백(' ') 또는 '<'를 만나면 현재까지 쌓인 `word`를 뒤집어 출력하고 초기화한다.
    -   공백은 그대로 출력한다.
4.  **잔여 처리**:
    -   순회가 끝난 후 남아있는 `word`가 있다면 뒤집어서 출력한다.

---

### 풀이 코드

```cpp
#include <iostream>
#include <string>
#include <algorithm>

using namespace std;

int main() {

    string s;
    getline(cin, s);

    bool inTag = false;
    string word;

    for (char c : s) {
        if (inTag) {
            cout << c;
            if (c == '>') inTag = false;
        } else {
            if (c == '<') {
                reverse(word.begin(), word.end());
                cout << word;
                word.clear();

                inTag = true;
                cout << c; 
            } 
            else if (c == ' ') {
                reverse(word.begin(), word.end());
                cout << word;
                word.clear();

                cout << ' ';
            } 
            else {
                word += c;
            }
        }
    }

    reverse(word.begin(), word.end());
    cout << word;

    return 0;
}
```
