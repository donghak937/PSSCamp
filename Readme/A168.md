## 문제 풀이

### 문제 링크
[135808. 과일 장수 – 프로그래머스](https://school.programmers.co.kr/learn/courses/30/lessons/135808)

---

### 문제 설명
> 과일 장수가 사과 상자를 포장하고 있습니다. 사과는 1점부터 `k`점까지의 점수로 분류됩니다.
> 한 상자에 사과를 `m`개씩 담아 포장하며, 상자의 가격은 `(가장 낮은 점수) × m`입니다.
> 과일 장수가 얻을 수 있는 최대 이익을 구하시오.
> (사과는 상자 단위로만 판매하며, 남는 사과는 버립니다.)

---

### 접근 방식
1.  **정렬**:
    -   최대 이익을 얻으려면 높은 점수의 사과끼리 묶어야 낮은 점수의 사과가 상자의 최저 점수가 되는 것을 방지하여 손해를 줄일 수 있다.
    -   따라서 사과 점수 배열 `score`를 내림차순으로 정렬한다.
2.  **상자 만들기**:
    -   점수가 높은 순서대로 `m`개씩 묶어서 상자를 만든다.
    -   내림차순 정렬되어 있으므로, `m`개씩 묶었을 때 `m`번째 사과(인덱스상 `m-1`, `2m-1`, ...)가 그 상자에서 가장 점수가 낮은 사과가 된다.
3.  **가격 합산**:
    -   각 상자의 가격 `(해당 상자의 최저 점수) * m`을 더해 총 이익을 계산한다.
    -   인덱스를 `m-1`부터 시작하여 `m`씩 증가시키며 해당 위치의 점수를 이용한다.

---

### 풀이 코드

```cpp
#include <vector>
#include <algorithm>

using namespace std;

int solution(int k, int m, vector<int> score) {
    sort(score.begin(), score.end(), greater<int>()); // 내림차순

    int ans = 0;
    for (int i = m - 1; i < (int)score.size(); i += m) {
        ans += score[i] * m;
    }
    return ans;
}
```
